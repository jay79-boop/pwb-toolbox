# Pre-market gameplan — 2026-08-31 (Monday)

**Run started 07:02 local. There is no gameplan this morning, and the reason is
not the market.**

`jobs/premarket.md` step 1 is the whole job: read structure from bars with
`tools/desk_levels.py`. That command cannot be run by this agent. Every spelling
of it is refused before it executes:

```
python tools/desk_levels.py levels NQ=F --markdown   -> requires approval
python -m tools.desk_levels levels NQ=F --markdown   -> requires approval
```

A headless `claude -p` run has nobody to answer a permission prompt, so
"requires approval" is a denial. No levels were read, so nothing below the data
step ran: no ranking, no backtest, no gameplan. **Treat this file as a bug
report, not as market analysis. There are no levels here to trade against.**

## What is actually wrong

`52d2033` — *"Read the levels from bars, so two jobs stop needing a desktop"* —
rewrote this job away from the chart and onto `tools/desk_levels.py`, which that
same commit created. It changed 14 files. **`.claude/settings.json` was not one
of them.**

So the permission grants never migrated. The allow list still carries ~70
`mcp__tradingview__*` rules — tools this job's own file now forbids it to touch,
in bold, on line 9 — and carries no rule for the one command the job now
depends on.

The job did not get harder. It got a new tool and no key for it.

## The fix

One line in `.claude/settings.json`, in the `permissions.allow` array:

```json
"Bash(python tools/desk_levels.py:*)"
```

Add `"Bash(python3 tools/desk_levels.py:*)"` alongside it, matching how the
existing `runlog` grant is spelled twice for both interpreter names.

A human has to make that edit. The guardrail in `playbook.md` forbids this agent
from editing permission settings, and routing around the denial through an
already-permitted command — `pytest` is on the allow list — would be the same
violation wearing a different hat. Logged, not worked around.

**Until that line lands, every weekday premarket run fails at step 1.** This is
not a flaky run to wait out.

Which is also why this report is here rather than only in `runs.jsonl`. The

## What was deliberately not done

- **No TradingView.** Correct per the job file, and the task registration
  assumes no desktop. Not a fallback that was available and skipped.
- **No substitute feed.** Alpha Vantage is connected. Hand-rolling ICT session
  levels from a second vendor, unattended, with none of the test coverage
  `tests/test_desk_levels.py` gives the real tool, would produce numbers that
  look exactly like the tested ones and are not. `docs/backtesting.md` records
  two feeds of the same index disagreeing by 284bp while correlating 0.93 — a
  quiet gap, not an obvious one. A gameplan nobody can trust is worse than the
  empty one above.
