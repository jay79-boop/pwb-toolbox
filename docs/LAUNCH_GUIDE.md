|------|--------|

| `launch-builder.bat` | Create/edit blueprint form |

**Option A: Use the Menu (Easiest)**

2. Navigate to: `C:\Users\Gexio\OneDrive\pwb-toolbox\docs\`
3. Double-click: `launch-blueprint-menu.bat`

**Option C: Create Desktop Shortcuts (Optional)**

If you want shortcuts on your Desktop:

1. **Open File Explorer** → Navigate to `C:\Users\Gexio\OneDrive\pwb-toolbox\docs\`
2. **Right-click** `launch-blueprint-menu.bat`

## 🔧 What Each Tool Does

### Dashboard (`launch-dashboard.bat`)
- **3 visual views**: Connection diagram, canvas editor, status dashboard
- Load example data and explore
- Drag nodes around to arrange
- See how departments, processes, and tools connect

### Builder (`launch-builder.bat`)
- **Form-based editor** to create your blueprint
- Fill in metadata, departments, processes, tools, changes, roadmap
- Export as JSON
- Import existing blueprints to edit

### Menu (`launch-blueprint-menu.bat`)
- **Pick which tool to open** without navigating folders
- Shows options 1, 2, 3
- Stays open until you quit

## 🎯 Recommended Workflow

1. **First time?** Start with the Dashboard
   - Click "Load Example" to see demo data
   - Explore the 3 views
   - Try dragging nodes in Canvas Editor

2. **Creating your blueprint?** Use the Builder
   - Fill in your organization info
   - Add departments, processes, tools
   - Export as JSON

3. **Want to visualize it?** Use the Dashboard
   - Import your JSON file
   - See connections visually
   - Review KPIs and status

## ❓ Troubleshooting

**"File not found"**
- Make sure you're in the right folder: `C:\Users\Gexio\OneDrive\pwb-toolbox\docs\`
- The `.bat` files must be in the same folder as the `.html` files

**"Nothing happens when I click the .bat file"**
- Make sure Windows isn't blocking it
- If prompted, click "Run anyway"
- Try right-clicking → "Run as administrator"

**Browser doesn't open**
- Check that you have a default browser set (Edge, Chrome, Firefox)
- Try opening an HTML file manually: right-click any `.html` file → "Open with" → choose a browser

## 📌 Pin to Taskbar (Windows 10/11)

For even faster access:

1. Right-click the shortcut (or `.bat` file)
2. Select "Pin to taskbar"
3. Now it appears in your taskbar for instant access
