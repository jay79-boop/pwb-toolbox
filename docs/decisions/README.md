# Decision log

One file per decision, newest first. **Append a new file; never edit this index
by hand for an unrelated change and never rewrite an existing entry** — a
decision is a record of what was believed and why, so a later correction is a
new entry that supersedes it, not a rewrite of the old one.

Naming: `YYYY-MM-DD-short-slug.md`, opening with an H1 title and a `*Decided
<date>.*` line.

Two branches adding two different files do not conflict. That is the entire
point of the directory; a single shared list is what used to collide.
