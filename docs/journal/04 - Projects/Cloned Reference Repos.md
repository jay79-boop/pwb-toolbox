# Cloned Reference Repos

Repos cloned purely as reference material — not verified working, no run-skill built, not tied to an active project. Distinct from the repos with a full [project note](Project Note Template.md), which were fully built, run, and verified for real. This note is the consolidation point for that lighter category so it doesn't spawn a full project note per repo.

**When something belongs here instead of getting a full project note:** it needs infrastructure not available locally (GPU, specific hardware, heavy multi-GB downloads) for its primary path, or it's pure demo/example/research code with no clear fit to any active project. See [Clone-and-Run Calibration](..\06 - Working Style\Clone-and-Run Calibration.md) for the full decision rule.
